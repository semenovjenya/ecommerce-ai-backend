# Статус миграции AI-ECOM на LangGraph-стек

Этот файл — единый execution ledger перехода. Архитектура и глобальный Definition of Done определены в [корневом README](README.md). Статус обновляется только по воспроизводимым доказательствам, а не по факту создания кода.

## Правила статусов

Использовать только следующие значения:

- `NOT_STARTED` — реализация не начата.
- `IN_PROGRESS` — есть незавершённые изменения, проверки или документация.
- `BLOCKED` — продолжение требует конкретного решения или внешнего условия; причина записана.
- `READY` — slice реализован и локально проверен, но зависит от следующего environment/cutover gate.
- `DONE` — реализация, проверки, evidence, rollback и документация завершены.

У каждого slice должен быть один write-owner. Несколько Codex subagents могут параллельно выполнять только независимый read-only анализ, поиск test gaps и review.

## Замороженные контракты

| Контракт | Значение |
| --- | --- |
| Graph / assistant ID | `commerce_agent` |
| Browser-facing runtime prefix | `/v2/agent/*` |
| Production runtime | Self-managed LangGraph OSS `commerce-agent` + dedicated PostgreSQL |
| Observability | LangSmith EU tracing + Langfuse, independent fail-open exporters |
| Realtime UI | `@langchain/react`, `useStream<CommerceState>` |
| Domain agents | Sales, Marketing, Supply, Price, Finance как фиксированные subgraphs |
| Deep Agents | Только policy-gated read-only research |
| Business core | FastAPI, SQL, calculators, simulations, outbox, audit, action execution |
| Cutover | Big-bang после staging acceptance; legacy images используются для rollback |
| Legacy history | Read-only; agent PostgreSQL threads не импортируются обратно |

Изменение любого значения требует обновления корневого README и отдельного architecture decision до реализации.

Исторические evidence-файлы ниже сохраняют формулировки, действовавшие на дату записи. Для следующих этапов зависимости в таблице slices имеют приоритет: после плановой поправки 2026-10-09 `M2` требует `M1.5`, даже если старый отчёт разрешал переход сразу после `M1`.
